# Bank Customer Churn Analysis

## Project Overview
This project analyzes bank customer data to identify churn patterns and high-risk customer segments.

## Tools Used
- Power BI
- Excel
- CSV dataset

## Data Source
- CSV file (Bank Customer Churn Prediction dataset)

## Key Analysis
- Overall churn rate
- Churn by age, credit score, balance, and geography
- Customer segmentation based on risk

## Key Insights
- Customers aged 51–60 show the highest churn
- Customers with low credit scores have higher churn risk
- Zero or very low balance accounts churn more frequently

## Outcome
Built an interactive Power BI dashboard to support customer retention strategies.
